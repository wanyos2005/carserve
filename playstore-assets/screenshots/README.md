# 📸 DriveOn Screenshots

This directory contains screenshots for Google Play Store submission.

## 📁 Directory Structure

- `phone/` - Phone screenshots (16:9 or 9:16 aspect ratio)
- `tablet/` - Tablet screenshots (16:10 or 10:16 aspect ratio)

## 📋 Required Screenshots

### Phone Screenshots (2-8 required)
1. `01_welcome_login.png` - Welcome/Login Screen
2. `02_home_dashboard.png` - Home Dashboard
3. `03_service_booking.png` - Service Booking Flow
4. `04_insurance_marketplace.png` - Insurance Marketplace
5. `05_social_hub.png` - Social Hub
6. `06_provider_details.png` - Provider Details
7. `07_vehicle_management.png` - Vehicle Management
8. `08_expense_tracking.png` - Expense Tracking

### Tablet Screenshots (1-8 required)
Same sequence as phone screenshots but optimized for tablet layout.

## 🎯 Screenshot Requirements

- **Format**: PNG or JPEG
- **Size**: Under 8MB per image
- **Quality**: High resolution, clean UI
- **Content**: Use demo/test data only
- **Theme**: Consistent across all screenshots

## 🚀 How to Take Screenshots

1. **Run the app**: `flutter run`
2. **Navigate to each screen** systematically
3. **Take screenshots** using device (Power + Volume Down) or emulator
4. **Save to appropriate directories** with correct naming
5. **Review and edit** if needed
